Règles de confidentialité / Privacy Policy

Dernière mise à jour : 13 octobre 2026

Cette politique de confidentialité décrit comment l'application Hermes Gmail MCP (« l'Application ») collecte, utilise et protège vos informations lors de son utilisation avec les services Google et Gmail.

1. Nature de l'application

Hermes Gmail MCP est un connecteur technique basé sur le protocole Model Context Protocol (MCP). Il est conçu pour un usage personnel et privé afin de permettre à l'agent conversationnel Hermes d'accéder aux fonctionnalités de messagerie électronique de l'utilisateur à sa demande explicite.

2. Données collectées et accès API Google

L'application utilise l'authentification OAuth 2.0 pour accéder aux données du compte Google de l'utilisateur. Selon les autorisations (scopes) accordées par l'utilisateur, l'Application peut accéder à :

  • Votre adresse e-mail Google (authentification et identification).
  • Les métadonnées et contenus de vos messages Gmail (lecture des e-mails, recherche, consultation des libellés).
  • La création, modification ou envoi d'e-mails, uniquement lorsque vous en donnez l'ordre à votre agent.

3. Utilisation des données

Les données obtenues via les API Google sont utilisées exclusivement pour exécuter les instructions fournies par l'utilisateur à son agent Hermes (par exemple : résumer les messages non lus, préparer un brouillon, rechercher un e-mail spécifique).

Aucune donnée n'est utilisée à des fins publicitaires, de ciblage, de profilage commercial ou de revente.

Conformité Google API Services User Data Policy :
L'utilisation et le transfert par Hermes Gmail MCP à toute autre application d'informations reçues des API Google respectent les Règles relatives aux données utilisateur des services d'API Google (Google API Services User Data Policy), y compris les exigences d'utilisation limitée (Limited Use requirements).

4. Stockage et sécurité des données

Les jetons d'accès et d'actualisation (tokens OAuth) sont stockés localement sur votre propre machine / infrastructure sécurisée. Les données de messagerie ne transitent par aucun serveur tiers et ne sont hébergées sur aucune base de données externe.

5. Partage avec des tiers

Aucune donnée utilisateur ni contenu d'e-mail n'est partagé, vendu, loué ou transféré à des tiers.

6. Révocation des accès et suppression

Vous pouvez à tout moment révoquer l'accès de l'application à votre compte Google via les paramètres de sécurité de votre compte Google : Gérer les autorisations de compte Google. La suppression du jeton local supprime immédiatement tout accès résiduel.

7. Contact

Pour toute question relative à cette politique de confidentialité ou au fonctionnement du connecteur, contactez l'administrateur : af.flavien@gmail.com.
